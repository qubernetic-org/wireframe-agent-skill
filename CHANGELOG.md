# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-03-18

### Added

- Initial skill definition (`SKILL.md`) with complete wireframe design system
- Full design language specification (`DESIGN-LANGUAGE.md`) — 21 sections covering colors, typography, borders, placeholders, watermark, components, grids, spacing, breakpoints, and forbidden elements
- 11 reusable component templates: Watermark, Navbar, Footer, PlaceholderBox, ProductCard, StatCard, ServiceCard, IconLabel, FormField, Button, Breadcrumb
- 7 responsive grid configurations
- Complete Tailwind CSS configuration and base CSS
- Single-page and multi-page layout templates
